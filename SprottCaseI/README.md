## Задание

На любом языке программирования реализовать моделирование хаотической системы методами:

- Эйлера;
- Эйлера-Кромера;
- Явной средней точки;
- КД: Рунге-Кутты 4 порядка (будет референсным методом).

Должно быть:

- Построение фазовых портретов;
- Построение временной области;
- Оценка ошибки между референсным и выбранным методом;

На звездочку:

Построение графика порядка:
$$\frac{Оценка\ ошибки\ с\ шагом\ h}{Оценка\ ошибки\ с\ шагом\ \frac{h}{2}}$$
при изменении шага h.
